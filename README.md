The Expression Tree Calculator is a web-based application developed during my second-year industrial training. It evaluates mathematical expressions by constructing and traversing an expression tree, offering both computation and visualization.

This project showcases my ability to integrate algorithmic problem-solving with full-stack web development using Django, HTML, CSS, JavaScript, and a Sqline database.

🔢 Expression Parsing: Converts infix expressions into an expression tree.

🌳 Tree Visualization: Interactive display of the expression tree structure.

⚡ Step-by-Step Evaluation: Demonstrates how the expression is computed.

🎨 Responsive UI: Built with HTML, CSS, and JavaScript for smooth interaction.

🗄️ Database Integration: Stores user inputs, history, and results using Slintr.

🔐 Authentication System: Secure login and registration via Django.
